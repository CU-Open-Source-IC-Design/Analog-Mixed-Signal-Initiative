# Getting Started

Welcome to the Open-Source Analog/Mixed-Signal IC Design Project Initiative!

## 1. Sign Up
Fill out the interest form (find on website or Instagram) so we can schedule meetings and add you to announcements.

## 2. Set Up Your Tools
Follow the **[Tool Setup and Workflow guide](Tool_Setup_and_Workflow.pdf)** before Meeting 1. It covers:
- Installing GitHub Desktop, Docker Desktop, and TigerVNC (plus WSL on Windows)
- Forking this repository and naming your fork `ams-<yourname>`
- Launching the design container and opening Xschem
- The branch and pull-request workflow

## 3. Checklist Before Meeting 1
- [ ] Interest form submitted
- [ ] Repository forked and cloned
- [ ] Container running and Xschem opens

Stuck? Open an [issue](https://github.com/CU-Open-Source-IC-Design/Analog-Mixed-Signal-Initiative/issues) or bring your laptop to Meeting 1.
